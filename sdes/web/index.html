算法规格

    

      

        
加解密公式

        
    
          
  • 加密: C = IP⁻¹( fK2( SW( fK1( IP(P) ) ) ) )
    • 
          
  • 解密: P = IP⁻¹( fK1( SW( fK2( IP(C) ) ) ) )
    • 
          
  • 密钥扩展: Ki = P8( Shifti( P10(K) ) ), i = 1, 2
    • 
          
  • 轮函数: fK(L, R) = ( L ⊕ F(R, K), R )
    • 
          
  • F(R, K) = SPBox( SBox1(左 4 bit) ‖ SBox2(右 4 bit) )
    •
